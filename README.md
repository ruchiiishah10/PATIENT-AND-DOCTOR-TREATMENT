# Patient and Doctor Treatment

A basic Python rule-based symptom checker created as an educational project for **Artificial Intelligence Concepts and Application (AICA)**.

## Project overview
The program asks the user to enter a symptom. It checks the input against a small predefined dictionary and displays a possible matching category with general advice. If the symptom is not in the example rules, it recommends consulting a qualified healthcare professional.

## AI concepts demonstrated
- Knowledge representation using Python dictionaries
- Rule-based matching
- Conditional logic
- Input normalization and output generation

## Supported example inputs
`fever`, `cough`, `headache`, `stomach_pain`, `cold`

## How to run
1. Install Python 3.
2. Download `patient_doctor_treatment.py`.
3. Open a terminal in the folder containing the file.
4. Run `python patient_doctor_treatment.py` (or `python3 patient_doctor_treatment.py`).
5. Enter one of the supported symptoms.

## Safety note
This project is an educational demonstration only. It is **not** a medical diagnosis, treatment plan, or prescription, and it has not been clinically validated. Seek help from a qualified healthcare professional for medical concerns, and get urgent assistance for emergency symptoms.
